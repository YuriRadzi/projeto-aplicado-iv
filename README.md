# CIÊNCIA DE DADOS - Universidade Presbiteriana Mackenzie

## Análise temporal da demanda por transporte público por ônibus no município de São Paulo entre 2015 e 2026
Estudo de séries temporais baseado no histórico de utilização de ônibus urbanos no município de São Paulo. Tentando obter informações valiosas para predição de valores futuros, ajudando no planejamento de linhas mais eficientes. 

* Fonte de dados: [Prefeitura de São Paulo - Mobilidade Urbana e Transporte]([https://www.kaggle.com/datasets/gpiosenka/coffee-bean-dataset-resized-224-x-224](https://prefeitura.sp.gov.br/web/mobilidade/institucional/sptrans))
